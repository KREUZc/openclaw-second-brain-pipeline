# mycrew_vault

## 命名規則
- 第一層：`NN_Title_Case`
- 第二層以下：`kebab-case`
- 檔案（時間戳）：`YYYYMMDD-HHMM-[slug].md`（slug 以英文/數字/`-`）

## 主要分區（目前）
- `00_Pupil/`：火花入口（Inbox/Processing）
- `01_Master_Projects/`：核心專案（0N）
- `11_Clipping/`：連結剪藏（1N，交由 mycrew 維護）
- `12_OpenClaw_Logs/`：對話/執行紀錄（1N，交由 mycrew 維護）
- `20_Runbooks/`：Runbook 單一真相（2N）
- `21_Crew_Own_Projects/`：mycrew 自我維運與技能規格（1N/2N）
- `97_FORBIDDEN/`：禁區（9N）
- `98_Archives/`：封存（9N）
- `99_Meta/`：系統協議、MOC（9N）

> 註：macOS 預設大小寫不敏感，禁止用「只改大小寫」做資料夾改名。
