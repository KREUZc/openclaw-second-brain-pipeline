# 11_Clipping

## Purpose
Inbox for external notes before project routing.

## Rules
1. Save new clipping notes here first.
2. Put attachments in `assets/`.
3. Route to project folder when topic is clear:
   - `vault/01_Master_Projects/<project>/clips/`
4. If attachments exist, move them with the note into:
   - `vault/21_Crew_Own_Projects/<project>/clips/assets/`
5. Update project `clips_log.md` with:
   - summary (50–100 chars)
   - next action (50–100 chars)
6. If target project is unclear, ask user before moving.

## Do not put here
- Private credentials / tokens
- Final long-term project indexes (put those under project folders)
