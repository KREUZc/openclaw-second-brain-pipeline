# Vault Folder Map (quick reference)

> Intent: keep this file short. It exists so an agent can decide where to read/write **without loading the whole protocol**.

## Core folders

- `00_Pupil/00-1_Inbox/`
  - Raw sparks (unaltered). First drop for new ideas.

- `00_Pupil/00-2_Processing/`
  - Distilled drafts, structured notes, decisions, next actions.

- `11_Clipping/`
  - External source clippings (links + short summary). Default for “user pasted a link”.
  - Assets: `11_Clipping/assets/`

- `12_OpenClaw_Logs/`
  - Session logs / transcripts / append-only work records.

- `01_Master_Projects/<project>/clips/`
  - Project-scoped routed clippings.
  - Assets: `<project>/clips/assets/`
  - Index: `<project>/clips_log.md`

- `03_Solid_Knowledge/03-1_Permanent_Notes/`
  - Atomic, citeable permanent notes.

- `99_Meta/MOC/`
  - Maps of Content, protocols, system entrypoints.

## Two-phase flow (recommended)
1) Capture (Inbox / 11_Clipping / Logs)
2) Route (Project clips / Processing / Permanent)
