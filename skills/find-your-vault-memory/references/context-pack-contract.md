# Context Pack Contract (for agents)

Goal: produce the smallest useful bundle for downstream work.

## Always include
- **Now**: 3–7 bullets (facts only, no speculation)
- **Open questions**: 1–3
- **Next actions**: 1–3 (each should be startable in 30 minutes)
- **Links** (3 max): best clip, best log, target folder

## Never include
- Full transcripts
- Long essays
- More than ~15 bullets total

## When to escalate
- Theme appears 3+ times in 7–14 days → propose upgrading to spec/runbook
- Multiple sources point to same project → propose weekly plan update
