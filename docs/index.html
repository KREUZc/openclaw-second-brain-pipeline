FAQ

Do I need Obsidian?
No. Obsidian is optional. The core is a file-based vault you can browse with any editor.
What if sources are login-gated?
Capture the link + what you saw. If extraction is blocked, paste text or add screenshots later. Keep the trace.
Will Inbox become a mess?
Inbox is append-only evidence. Refinement happens via copies (Processing/Logs). Use a review rhythm, not deletion.
